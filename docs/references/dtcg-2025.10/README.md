# DTCG specification 2025.10

This directory is a local snapshot of the Markdown sources for the stable **Design Tokens Community Group (DTCG) 2025.10** technical reports, published 28 October 2025.

The official publications are:

- [Design Tokens Format Module 2025.10](https://www.w3.org/community/reports/design-tokens/CG-FINAL-format-20251028/)
- [Design Tokens Color Module 2025.10](https://www.w3.org/community/reports/design-tokens/CG-FINAL-color-20251028/)
- [Design Tokens Resolver Module 2025.10](https://www.w3.org/community/reports/design-tokens/CG-FINAL-resolver-20251028/)

These are stable Final Community Group Reports intended for implementation. They are not W3C Recommendations and are not on the W3C Standards Track.

## Provenance

The files were copied without modification from the official [`design-tokens/community-group`](https://github.com/design-tokens/community-group) repository at publication commit [`f0f32a7dce0b51b36488be9cbbf7cad2763c6f29`](https://github.com/design-tokens/community-group/commit/f0f32a7dce0b51b36488be9cbbf7cad2763c6f29). The maintainers author each report as multiple Markdown chapters and generate the published HTML with W3C ReSpec; there is no official single-file Markdown or PDF edition.

The copied material is licensed under the terms in [LICENSE.md](./LICENSE.md). Treat these files as vendored reference material rather than project-owned documentation.
