# Status History

This directory contains selected snapshots of `../current.md` from completed phases or significant handoffs. It is an audit aid, not a session transcript and not a substitute for Git history.

## When to archive

Create an archive entry when:

- a major project phase ends;
- the primary product or implementation focus changes materially;
- a long-running workstream is handed to another contributor or agent; or
- the outgoing snapshot contains context that would be difficult to reconstruct from authoritative documents and Git history alone.

Routine progress does not require an archive entry.

## Naming and contents

Use:

```text
YYYY-MM-DD-short-description.md
```

Copy the outgoing `current.md`, then add a short note identifying when it was superseded and which newer snapshot replaced it. Do not revise archived snapshots to match later decisions; correct the authoritative project documents and the live snapshot instead.
