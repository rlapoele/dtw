Preserve tool failures; execute bounded alternative native mechanism qualification if available. Native OS picker behavior remains separate.

## Source scope and resource limits

Prototype codec is closed, duplicate-aware and prototype-safe for inspected bounded inputs. Decoder scans before visitor parsing and rejects whole. `encode` (`codec.mjs:41`) serializes the complete in-memory candidate before semantic/entity/string limits; `safeData` guards shape hazards/depth but does not bound aggregate work before serialization. Therefore this source does not establish safe preallocation for arbitrary injected in-memory input. Before any production reuse, bound candidate traversal/output before expensive materialization. Standalone `schedule`/`arithmeticGuard` probes are not an integrated evaluator or proof every operation checks before allocating/revisiting. Retained-record metadata decoding, ownership-enforced write API, 25-record acceptance, coherent app reads, draft behavior, replacement and domain diagnostics remain deliberately absent and unqualified.
