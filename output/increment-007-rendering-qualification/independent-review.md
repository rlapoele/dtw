## Instrumentation and candidate boundaries

The automatic runner stop predicate checks only Long Tasks / `RunTask`; both are
empty in this known failing trace. Consequently R03-raw remains `observed`, no
`r.stop` is set and process success is not a performance verdict. That is a real
instrumentation limitation, already withdrawn explicitly by the report. The frozen
runner ends after the row/raw cases and contains no larger or Safari continuation;
manual trace inspection found the failure before any escalation. This does not
invalidate the negative trace. **Before any reuse or positive qualification**, make
the automated verdict consume renderer-main layout/whole-task evidence, fail closed
when required evidence is missing, and preserve a failing/inconclusive stop result.
Do not infer a pass from this runner's exit code or `observed` labels. No rerun is
needed merely to reproduce the already measured failure.

The report also correctly declares the candidate incomplete. Batches include full
authored tokens (the raw fixture's initial row message is about 4.13 MB despite its
tiny visible summary), and inspection returns a full project. Synthetic paths and
resolution replace actual application derivation. Group/native-option preparation,
All content, complete exact-ID reachability, delayed-response fencing and worker
replacement are absent/unqualified. Raw request checking uses a captured selection;
it is not a proven current-selection fence. These adapters must not be adopted as a
qualified boundary. None is needed to manufacture or explain away the independently
observed raw-layout counterexample.

`content-visibility:auto` is applied per ordinary row with an intrinsic estimate,
not fixed clipping or constant DOM. No completed maximum DOM/text/memory or repeated
activation/reflow evidence exists. Growing arrays/reconciliation, full choices,
full-project inspection returns and lazy heavy trace preparation remain unresolved.
The experiment cannot establish that staged ordinary rows are impossible, nor that
fixing raw details alone would qualify the complete approved candidate.
