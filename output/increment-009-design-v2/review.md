# Increment 009 Design V2 — rendered observations

13 November 2026. Coordinator review of the separately prepared designer artifact,
following user agreement of the precise naming policy and authorization of V2
mockups. These are mockup observations, not renewed analyst consistency review,
production validation or application implementation acceptance.

## Scope and observations

[The gallery](index.html) contains ten accepted captures covering the eight preset
states plus unrelated local creation and compact navigation. Desktop DOM viewport
was measured at 1280 × 800 CSS pixels; compact navigation used 1000 × 800. Browser
zoom affected physical capture dimensions, so the gallery crops unused outer canvas;
original PNGs are retained. Viewport override was reset at handoff.

- Raw spaced/capitalized input remained editable with prepared name/path preview.
- Changing the parent to foundation exposed three collisions spanning token types
  and groups. Submitting preserved raw input, focused rejection feedback and did
  not create a fixture. The modal body scrolls; its actions remain visible.
- Reviewed Straße/STRASSE, accented canonical equivalence, group rename with
  affected descendant paths, and empty-after-removal feedback. Empty names show
  no valid candidate path.
- Selected the two identically displayed token paths independently and observed
  different exact identities/types in the inspector. Enter activated the second
  row from its native button. Each ambiguous row includes associated identity and
  context rather than a detached identity list.
- The missing-parent fixture stayed accessible with its actual local name and
  exact identity; its inspector stated that the path was unavailable. Scrolling
  the inventory revealed the selected orphan row alongside its inspector.
- A local creation using ` Fresh Accent ` produced `freshaccent`, an opaque-black
  sRGB fixture at root, with the three pre-existing conflicts unchanged. This is
  presentation of the collision-policy allowance only. It does not demonstrate
  all current application structural/reference checks: the mixed fixture also
  includes an orphan. AC-10 still requires an otherwise allowed command.
- The compact navigation remained a full-height left-edge drawer with one active
  view. Restore/backup/project/persistence actions are deliberately disabled.

Prototype corrections before handoff restored the existing explicit-black color
creation rule, retained metadata controls in a review disclosure, removed wording
that implied automatic read-only legacy data, bounded long modal bodies while
keeping actions accessible, and replaced an empty candidate path with No valid
path yet. The full-fold explanation describes both stored-name examples accurately.
V1 and production code remained unchanged.

## Limits and stopping record

Approximately **12–15 aggregate render-review minutes** (estimate across coordinator
and designer), **zero harness-repair cycles**, of the shared 15-minute/one-repair
ceiling. Review is stopped. One transient reload screenshot failure was followed
by a valid settled capture; stale controls during live edits were retargeted from
fresh DOM state. No harness or application changes were made to satisfy automation.

The fixture helper is explicitly limited: host lowercase/normalization plus fixed
fold examples do not qualify pinned Unicode 17.0.0 or complete D145 conformance.
No domain/application validator, worker, persistence, strict backup/restore,
revision/concurrency/recovery, progressive-rendering or resource qualification
was implemented or exercised. No tests or production build ran. Ordinary editor
and resolution design remains in V1. Metadata-disclosure placement is illustrative,
not final full-form agreement. This is not full keyboard/accessibility/browser
support certification.

D9-1 is represented by a proposed per-entry treatment; it is not closed by an
independent review. Next gate: user review of identified V2, then explicit approval
for analyst review. Final contract/design agreement and implementation authorization
remain pending. Earlier 007/008 and V1 verification campaigns remain stopped.
