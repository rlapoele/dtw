## Scope and publication

Only `publication-manifest.json` routes can be served. The server reads the exact
listed `publish/` files once, verifies hashes/lengths and rejects symlinks before
binding 127.0.0.1. Requests index that immutable map directly. There is no URL-to-
filesystem resolution, directory listing, proxy, POST/evidence/write endpoint,
query normalization, extension fallback or runtime import outside the bundle.
`prepare.mjs`, the server, tests, manifest and all output are **not public routes**.
The manifest gives every public route, byte count, SHA-256, MIME and provenance.

The 12-file bundle is 108,964 bytes. Codec and fixture copies are byte-identical
frozen Stage A modules. All six jsonc-parser 3.3.1 ESM dependency modules and the MIT
notice are copied exactly. Five explicit extensionless aliases satisfy its original
imports; they are exact routes, not filesystem fallback. No original repository
root/source engine, real project, report, profile, credentials, absolute user path
or environment value is published. All browser records are small synthetic data.
No production decoder, durable acceptance, concurrency fencing, rendering, lifecycle,
performance, normal-profile retention or whole-browser-support certification follows.

## Cases prepared

1. Same-origin actual module worker readiness, secure top-level origin and native
   worker capabilities. After HTTPS exposure record the actual browser certificate
   trust, edge certificate chain and served headers; `isSecureContext` alone is not
   TLS evidence.
2. Strict-durability native write: request success then complete; explicit abort
   after request success; exact prior record preserved. Strict is a completion hint,
   not proof against power loss. One small frozen coverage fixture only.
3. Two actual workers: first exclusive Web Lock acquired, contender unavailable,
   explicit release followed by contender acquisition. No stress or watchdog case.
4. Exact byte transfer in each direction with sender buffer detachment; frozen
   codec decode/encode and complete canonical snapshot equality preserve Unicode
   code units, opaque identities, exact decimals/values, aliases and composites.
5. Blob link downloads the exact synthetic backup. File input accepts only that
   complete byte sequence (and a 64 KiB bound), then transfers/decodes/writes it into
   a fresh empty own database and verifies exact readback/regenerated bytes. Actual
   selected file hash/name/bytes and strict event trace are recorded. A programmatic
   file-input assignment qualifies File/Blob processing, **not OS picker operation**.
   Native dialog selection/cancel require separately attributed actual UI evidence.
6. `/blocked` serves the same page with `worker-src 'none'`; actual CSP worker denial
   leaves controls disabled, zero storage calls and no synchronous/volatile fallback.
   `/capability-failure` is explicitly labelled injected required-Worker denial;
   it is not an observed browser missing capability. No TLS setting is changed.

The default CSP is `default-src 'self'; script-src 'self'; worker-src 'self';
connect-src 'self'; object-src 'none'; base-uri 'none'`. Blob is used only as a
navigation/download URL; no blob script/worker/connect exemption is required.
Page evidence stays in `window.h.snapshot()` and visible selectable JSON. The
server never accepts results. Automation may read this object via normal browser
instrumentation into local output, without adding published collection endpoints.
The page fails closed on its 8-second bounded RPC timeout and never escalates data.

```sh

```

Keep that process handle and its printed actual port. Create an empty task-owned


Launch with a small explicitly constructed child environment containing ordinary
PATH/TMPDIR only (no inherited Cloudflare token/config environment), without

edge uses normally validated public HTTPS; cloudflared→dedicated loopback origin
